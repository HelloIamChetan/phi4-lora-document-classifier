# Example review queue entry

This illustrative entry uses the repository’s [fictional insurance policy](examples/fictional-insurance-policy.txt). The suggestions below are examples for the interface.

| Review queue field | Example |
| --- | --- |
| Document | Private Health Insurance Policy Summary |
| Suggested category | Finance |
| Suggested retention score | 4 / 5 |
| Reviewer state | Awaiting review |
| Reviewer actions | Accept suggestion, edit category or score, or skip |

The review makes it possible for a person to choose a different category, such as a health-related label, before saving the metadata. The queue displays and records suggestions for review while the source file stays in place.
